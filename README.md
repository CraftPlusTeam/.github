# CraftPlusTeam profile

組織トップページの紹介文とビジュアルを管理します。

## 活動実績の更新

Node.jsとGitHub CLIを使用します。組織の全対象リポジトリを読み取れるアカウントで実行してください。アクセスできるリポジトリのみが集計されるため、部分的な権限のトークンを使うと過少集計になります。

```sh
node scripts/update-stats.mjs
```

- コミット数: 各リポジトリのデフォルトブランチから到達できる全履歴の合計。マージコミットを含み、リポジトリ間の同一コミットは重複排除しません。
- リポジトリ数: 公開・非公開を含む読み取り可能な組織所有リポジトリ数。プロフィール用リポジトリ・フォーク・アーカイブも含みます。
- マージ済みPR数: 対象リポジトリのMERGED状態のPRを合算します。
- 非公開リポジトリ名・コミット内容・個人情報は出力しません。
- API失敗時は既存画像を保持します。数値は画像内のUTC日時時点のスナップショットです。

更新画像は作業ブランチへcommit/pushし、PRレビュー後にマージします。自動更新を設定する場合もこのPR経由の手順を維持してください。通常のGITHUB_TOKENは他の非公開リポジトリを読み取れないため、組織全体の集計には別途、読み取り権限を絞った認証の設定が必要です。
