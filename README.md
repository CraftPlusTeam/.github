# CraftPlusTeam profile

Pui-coreの個人プロフィールをベースに、ダーク背景・シアン・波形とタイピングアニメーションで構成した組織トップページです。

## 集計と更新

Node.jsとGitHub CLIを使用します。全対象リポジトリと組織メンバーを読み取れるアカウントで実行してください。

```sh
node --test scripts/update-stats.test.mjs
node scripts/update-stats.mjs
```

- 各リポジトリのデフォルトブランチSHAを固定して全コミットをページ送りで取得します。マージコミットを含み、同一リポジトリ内の同一SHAは重複排除、リポジトリ間の重複は維持します。
- 現在の組織メンバーのGitHub author.loginと大文字小文字を無視して照合します。コミッターやCo-authored-byからの加算はしません。退会者・bot・未紐付けはOtherへ合算します。
- メンバーが存在してコミット0件なら0件として表示します。空リポジトリもリポジトリ数に含めます。
- 組織APIの公開・非公開リポジトリ総数と取得数が一致しない場合や、非公開総数を確認できない場合は更新を中止します。
- マージ済みPRはclosed PRのmerged_at有無で集計します。
- 言語はLanguages APIのバイト数を合算。上位7言語とOther（8言語以下はすべて）を表示し、端数調整で表示比率を100.0%に揃えます。GitHub Linguistの分類に従い、言語データ取得時の状態を使います。
- APIレスポンスはメモリ上だけで処理。SVGと標準出力には許可されたメンバー名・集計値・言語名・日時だけを出力します。リポジトリ名、メール、コミット内容は保存しません。
- API失敗時は既存画像を保持します。画像は日時付きスナップショットで、定期更新は未設定です。

生成された画像は作業ブランチへcommit/pushし、PRレビュー後にマージします。通常のGITHUB_TOKENでは他の非公開リポジトリを読み取れません。既存の広い権限を持つCLI認証を公開Actionsへ転用しないでください。

## アニメーション

画像はリポジトリ内のSVGで完結し、外部のバナーや統計サービスには依存しません。波はゆっくり往復し、キャッチコピーはタイピング表示、メンバーバーは初回に伸びます。READMEのpicture/sourceでprefers-reduced-motionを判定し、静止版SVGへ切り替えます（画像内CSSのメディア判定だけには依存しません）。静止版は集計スクリプトで同時生成します。
