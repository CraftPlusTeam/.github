<details>
<summary>集計について</summary>

- 公開・非公開リポジトリを含む、画像内のUTC日時時点のスナップショットです。
- コミット数は各デフォルトブランチの全履歴を合算し、マージコミットも含みます。リポジトリ間の重複は除外しません。
- GitHubのauthorアカウントに基づいて現在の組織メンバーへ集計します。それ以外・未紐付けはOtherにまとめ、名前やメールから推測しません。
- 言語比率はGitHub Languages APIのバイト数を合算した割合です。コミット数や開発時間の割合ではありません。
- 非公開リポジトリ名・コード・メールアドレスは掲載しません。定期自動更新は未設定です。

</details>
